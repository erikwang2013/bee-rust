# Beerust

[简体中文](../README.md) · [English](README.en.md) · [한국어](README.ko.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português](README.pt.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · [বাংলা](README.bn.md) · [Bahasa Indonesia](README.id.md) · [日本語](README.ja.md)

Beerust — это производственный веб-фреймворк на Rust, философия дизайна которого берёт начало во фреймворке Beego (Go) и переосмыслена в идиомах Rust: trait, макросы и система типов.

## Талисман проекта: Rusty

<img src="rusty.svg" width="360" alt="Rusty завис анфас, крылья развёрнуты кольцом, в передних лапках — ржаво-оранжевый ящик с инструментами">

### Карточка персонажа

**Имя** Rusty (Расти) — цвет ржавчины, в честь Rust, и та самая ржавчина, что пачкает его комбинезон.

**Внешность**: пушистая пчела-инженер. Янтарно-золотой пушок покрывает круглое брюшко, три угольно-чёрные полосы — как перекошенные лямки рабочего комбинезона; четыре прозрачных крыла настолько тонкие, что просвечивают, а при зависании сливаются в дрожащий шлейф; фасеточные глаза — два стеклянных шарика обсидиана с бликом на каждом; в передних лапках — отполированный до блеска ржаво-оранжевый ящик с инструментами. Это его корзинка для пыльцы, в которой никогда не бывает пыльцы — только зависимости.

**Характер**: трудоголик, оптимист, лёгкая степень перфекционизма.

- Чиня улей, поочерёдно проверяет каждую ячейку антеннами — придирчиво, будто прогоняет lint
- Зависимости в корзинке для пыльцы зафиксированы по версиям намертво — кто тронет, тот и получит
- Гоняясь за багом, зависает неподвижно в воздухе, крылья превращаются в одно размытое кольцо
- В день релиза новой версии исполняет у входа в улей пчелиный танец-восьмёрку

### Визуальные стандарты

| Элемент | Описание |
|------|------|
| Корпус | Янтарно-золотой `#F5B301`, пушок на брюшке короткий и плотный, по краю — кольцо бликов |
| Полосы | Угольно-чёрный `#1F1A17`, три полосы, только на брюшке |
| Крылья | Прозрачно-голубой `#CFE8F5`, непрозрачность 40%, видны прожилки |
| Фасеточные глаза | Тёмно-коричнево-чёрный `#2A1E16`, овальные, блик в верхнем левом углу |
| Акценты | Ржаво-оранжевый `#B7410E` (ящик с инструментами, бабочка) — ржавый цвет его визитная карточка |

### Набор эмоций

| Эмоция | Изображение | Когда |
|------|------|---------|
| Полон энергии | `(^o^)` пушок дыбом, крылья вибрируют на высокой частоте | когда все тесты зелёные |
| Зависание-отладка | `o(°▽°)o` висит в воздухе, от крыльев лишь шлейф | когда преследует упрямый баг |
| Возвращение с полным грузом | `(≧▽≦)` ящик распух, летит слегка покачиваясь | когда новый драйвер успешно подключён |
| Дремлет | `(-_-)zZ` сидит у входа в улей, антенны обвисли | ночью, когда трафик затих |
| Шерсть дыбом | `(#°益°)` жало поднято | когда фильтр безопасности отразил атаку |

### Фирменные движения

1. **Зависание-отладка** — обнаружив баг, зависает над кодом, крылья гудят в размытом ореоле, смотрит неотрывно, пока ты не исправишь.
2. **Танец-восьмёрка** — при каждом релизе облетает улей полным кругом, возвещая всему рою: «Цветы распустились». Настоящие пчёлы так передают расположение источника нектара, Rusty так передаёт changelog.
3. **Чистка** — передними лапками снова и снова проводит по антеннам. Думаешь, он красуется? А он проверяет, не подхватила ли конфигурация горячее обновление.

### Где его можно встретить

- **Логотип**: завис анфас, крылья образуют кольцо вокруг названия.
- **Страница 404**: завис над пустым цветочным полем, растерянно кружит — «А где мёд?»
- **CLI**: рядок пчёлок на стартовом баннере; пока идут тесты, сидит рядом и надзирает.
- **Анонсы релизов**: тот самый кадр с танцем-восьмёркой.

## Цели дизайна

| Цель | Показатель |
|------|------|
| **Удобство разработки** | от `bee-rust new` до первого запроса < 30 секунд |
| **Производительность** | накладные расходы слоя контроллеров < 5% (относительно чистого axum), P99 задержка маршрутизации < 100µs |
| **Скорость компиляции** | полная сборка мета-crate < 60s (release), инкрементальная < 5s |
| **Размер бинарника** | минимальное приложение (только router) < 5MB (strip + LTO) |
| **Безопасность** | 0 unsafe в коде приложения; весь FFI обёрнут в отдельные crate `*-sys` |
| **Совместимость** | Rust 1.80+ MSRV, следуем за stable |

## Принципы дизайна

1. **Философия Beego, выраженная в Rust** — MVC, пространства имён, цепочки фильтров реализованы через trait + макросы
2. **Прогрессивное улучшение** — минимальное ядро зависит только от axum + tokio, всё остальное за feature-флагами
3. **Явное лучше неявного** — регистрация маршрутов, маппинг моделей, порядок middleware — всё объявляется в коде явно
4. **Абстракции с нулевой стоимостью** — статическая диспетчеризация через trait, макросы раскрываются на этапе компиляции, без накладных расходов виртуальных функций
5. **Независимость хранилищ** — реализацию каждого движка можно заменить отдельно, не затрагивая бизнес-логику верхнего уровня
6. **Наблюдаемость из коробки** — инструментирование tracing + metrics покрывает весь фреймворк, структурированное логирование включено по умолчанию

## Архитектура

### Топология crate

```
bee_rust/           # мета-crate, re-export + feature-флаги
bee_router/         # маршрутизация + контроллеры + Context + цепочка фильтров
bee_orm/            # ORM — trait Model + QuerySet + Migration + маппинг связей
bee_kv/             # единая абстракция KV/кэша — Redis + Memcached
bee_search/         # поисковый/аналитический движок — Elasticsearch + OpenSearch + ClickHouse
bee_graph/          # графовая БД — Neo4j + NebulaGraph + ArangoDB
bee_tsdb/           # БД временных рядов — InfluxDB + Apache IoTDB + QuestDB
bee_config/         # управление конфигурацией — INI/YAML/ENV + горячая перезагрузка
bee_cache/          # абстракция кэша — Memory/Redis/Memcache
bee_session/        # Session — бэкенды Memory/Redis/Cookie/Database
bee_logs/           # логирование — многоуровневые логи + интеграция tracing
bee_template/       # рендеринг шаблонов — на основе tera
bee_cli/            # CLI — скаффолдинг/генерация кода/запуск в разработке/упаковка (переезд в планах)
```

### Цепочка фильтров запросов

```
Запрос → [SecurityFilter обнаружение атак] → [восстановление Session] → [валидация параметров] → [хук prepare] → [обработка handle] → [хук finish] → Ответ
```

## Обзор возможностей

Обзор возможностей ниже; подробное использование модулей, примеры кода и описание API — в [справочнике API](api.ru.md).

### Веб-ядро (bee_router)

MVC-контроллеры: trait `Controller` + `Context` с поддержкой пространств имён маршрутов, регистрации RESTful-методов и цепочки фильтров запросов.

- Вывод ответа: `ctx.json()` / `ctx.text()` / `ctx.html()`
- Перенаправление / прерывание: `ctx.redirect()` / `ctx.abort()`
- Сессия и параметры: `ctx.session` / `ctx.params`

### Обнаружение атак (feature `security`)

Фильтр обнаружения атак на основе [security-rust](https://crates.io/crates/security-rust), покрывает 27 типов атак: XSS, SQL-инъекции, инъекции команд, SSRF и другие. Включается одной строкой:

```rust
let security = SecurityFilter::new();  // все 27 детекторов включены
```

### ORM (bee_orm)

Производный макрос `#[derive(Model)]` + цепочные запросы QuerySet (filter / order_by / limit), поддержка SQLite, PostgreSQL, MySQL, TiDB.

### Управление конфигурацией (bee_config)

Производный макрос `#[derive(Config)]` с загрузкой INI / YAML / ENV и горячей перезагрузкой.

### Движки хранения

Единая trait-абстракция для KV / Cache (Redis + Memcached), поисковых движков (Elasticsearch / OpenSearch / ClickHouse), графовых БД (Neo4j / NebulaGraph / ArangoDB) и БД временных рядов (InfluxDB / IoTDB / QuestDB); драйверы компилируются по feature-флагам.

### Session, логирование, шаблоны

- Session: несколько бэкендов — Memory / Redis / Cookie / Database
- Логирование: многоуровневые логи + интеграция tracing
- Шаблоны: рендеринг на основе tera

### Инструменты CLI

```bash
bee-rust new my-app            # создание скаффолда проекта
bee-rust generate controller user
bee-rust run --watch           # запуск в разработке (горячая перезагрузка)
bee-rust pack                  # упаковка для развёртывания
```

```bash
# клонируем репозиторий
git clone https://github.com/erikwang2013/bee-rust.git
cd bee-rust

# сборка
cargo build --workspace

cargo test --workspace
```

```bash
# создаём новый проект через CLI
```
